# Prisoners-Dilemma

This project contains a tool to simulate the outcome of the iterative prisoner's dilemma (IPD). It includes various strategies commonly used in the famous thought experiment, a simple interface, and a method for visualising the outcome of the simulation. It also allows for the specification of a gains matrix, representing the respective gains or losses of each combined outcome to each player. The _TEST_ file contains a working example of such a simulation.

This tool was created for the eventual purpose of a study on the effectiveness of a simple game theory model of OPEC oil trade, in an attempt to predict drastic changes in price as a function of simplified quantified scores of international relations.

### Dependencies

The tool relies only on the _numpy_ and _pyplot_ libraries for functionality, as well as _tkinter_ for the optional interface.
